Kant van de externe router

Eén keer plakken in de terminal
/interface/wireguard add name=mm-wg listen-port=13231
/interface/wireguard/peers add interface=mm-wg public-key="hT7mQ2vXc9LrE4wYb1NzKp8sUo3aFd6GjZx5CqViW0M=" \
    endpoint-address=hg309a1b2cd.sn.mynetname.net endpoint-port=13231 \
    allowed-address=10.255.0.1/32 persistent-keepalive=25s
/ip/address add address=10.255.0.2/32 network=10.255.0.1 interface=mm-wg
/ip/firewall/filter
add chain=mm-tunnel src-address=10.255.0.1 protocol=tcp dst-port=443 action=accept comment="mm: alleen REST API"
add chain=mm-tunnel action=drop comment="mm: rest van de tunnel dicht"
add chain=input in-interface=mm-wg action=jump jump-target=mm-tunnel place-before=0 comment="mm: management"
add chain=forward in-interface=mm-wg connection-nat-state=!dstnat action=drop place-before=0 \
    comment="mm: niet routeren"
add chain=forward out-interface=mm-wg connection-state=new action=drop place-before=0 \
    comment="mm: LAN niet de tunnel in"
:put [/interface/wireguard get mm-wg public-key]
Handshake gelukt 4 seconden geleden, vanaf een CGNAT-adres
